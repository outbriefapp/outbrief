汇报的语音全部在这台设备上直接请求你选的语音平台，server 看不到简报的明文。**默认用免费的 Azure 声音，不用任何配置。**

「设置 → 语音」这一页从上到下是：汇报语言 → 平台 → 平台需要的配置 → 模型 → 声音 → 语速 → 测试合成。

## 汇报语言

汇报语言决定简报用哪种语言写、用哪种语言念，跟汇报原文是什么语言无关。通话中的回答也会用这种语言。

- 支持 90 个语言和地区，例如「中国台湾」「墨西哥西班牙语」。
- 默认跟随系统语言。
- 改了以后会同步给电脑上的 daemon，下一份简报就用新语言写。

## 选平台

<Tabs>
<TabItem label="内置平台">

在下拉框里选。每个平台各存一份配置，切换平台不会丢掉之前填好的 Key 和声音。

| 平台 | 需要什么 | 备注 |
|---|---|---|
| **Azure** | 什么都不用填 | 默认平台，免费，声音跟着汇报语言走 |
| ElevenLabs | API Key | 任何音色都能读它支持的所有语言 |
| MiniMax | API Key | 国内站和国际站的 Key 不通用；音色按语言区分 |
| 豆包 | API Key（新版控制台）或 App ID + Access Token（旧版） | 2.0 音色能自动识别 30 多种语言 |
| 阿里云百炼 | API Key | 北京和新加坡的 Key 不通用；不支持调语速 |
| 腾讯云 | SecretId + SecretKey | 只适合中文和英文 |
| OpenAI | API Key | 可以改接口地址，走代理或兼容服务 |
| Gemini | API Key | 不支持调语速 |
| Grok | API Key | 支持 20 种语言 |
| ChatTTS | 自部署地址 | 不支持调语速 |
| IndexTTS | 自部署地址（vLLM-Omni） | 音色是你上传的参考音频 |
| CosyVoice | 自部署地址 | 采样率要和服务端模型一致 |

</TabItem>
<TabItem label="自定义接口">

接入任何 TTS 都只需要粘贴一段 cURL：

<Steps>

1. 把平台文档里的 curl 示例粘贴进来，点「导入」。
2. App 会自动认出句子、音色和语速字段。认错了就点那三行按钮，换成正确的字段。
3. 选响应格式：「响应体就是音频」，或者「JSON 里的字段」（再填字段路径，比如 `data.audio`，并选 Base64 / Hex / 音频链接）。
4. 没有文件头的裸 PCM，选「裸 PCM（16 位单声道）」并填采样率。
5. 点「测试合成」试听。

</Steps>

导入后的请求会原样只读显示，要改就重新粘贴一次。

</TabItem>
</Tabs>

## 声音和语速

- **声音**：按女声和男声分组，显示的是名字，不是编码。支持复刻音色的平台（MiniMax、豆包、ElevenLabs 等）可以填自己的音色 id，或者点「获取音色」把账号里的复刻音色拉下来。
- **语速**：0.5×–2× 的滑块，会自动限制在各平台支持的范围内。不支持语速的平台，滑块下方会注明。
- **测试合成**：用当前页面上的配置直接念一句，不用先保存。失败时会显示接口返回的原因。

<Aside type="tip">
API Key 只存在这台设备上。保存后只显示 `sk-…abcd`，要换就点「更换」。
</Aside>

## Platforms

| Platform | File | Notes |
|---|---|---|
| macOS (Apple Silicon) | `OutBrief_<version>_aarch64.dmg` | Ad-hoc signed, not notarized with a Developer ID. If the browser download is blocked, right-click the app in Finder → Open, or run `xattr -cr /Applications/OutBrief.app` |
| Android (arm64) | `OutBrief_<version>_arm64.apk` | Package `ai.outbrief.app`. Installs directly and includes call pushes. After install, turn on background calls as described in [Background calls](/en/docs/guides/background-calls/) |
| iOS, Windows, Linux | No installer yet | Build from source, see [Install the app](/en/docs/app/) |

The app alone does not get calls. The computer that runs the agents also needs the daemon, paired into the same account. See [Quick start](/en/docs/quick-start/).
